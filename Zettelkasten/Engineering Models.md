# Engineering Models

## Notes

Models are a purposeful representation of an idea, item, concept or essentially anything. Models are used to better understand a problem, slow down interactions, represent ideas, test functionality, account for certain situations, and document progress.

![[Pasted image 20260406013435.png]]
There are many types of models but the two main ones are 
	1. Descriptive - Visual representation to convey what words cannot fully describe
	2. Predictive - Analytical representation using data to predict the behavior of a system
Some other types of models that stem from this are mathematical, material, and visual.

Models typically have a three-tier design process
	1. Early - Rough drafts with a generalized outline
	2. Refined - Adds more detail
	3. Finalized - Full representation of the system

![[Pasted image 20260406013557.png]]
Models for objects or visual models are best represented orthographically. Orthographic views are a 2D projection onto a plane representing each dimensional side of the object being modeled. Orthographic views have 3 sides; front, side and top. These views are aligned so that sides are dimensionally accurate between each drawing. In these drawing solid lines represent an edge that can be seen and a dashes line is an edge that is known but can't be seen from that particular viewpoint.

![[Screenshot 2026-04-06 013858.png]]

![[Pasted image 20260406013933.png]]
Dimensions are important for having another reference that can assist with making the model. Every line dimension needs to be labeled at least once. Arrows represent the boundaries of the measurement and can be either inside the line or outside. Circle dimensions are prepended with either an R (radius) or Phi φ (diameter). Units need to be labelled and can be either next to the measurement or as an index.

"It is best to use predictive models instead of wasting time, money and resources constantly building numerous prototype"

Predictive models normally are mathematically based on established formulas and help predict the behavior of a system. These models help adjust the design of a project early on before having to prototype. This reveals strength and weaknesses in the system while being less constrained. It is important to understand any assumptions that the mathematical formulas are making when used in a predictive model and make sure they are relevant to the situation.

Empirical models are a type of predictive model that is based on observation and adapts to the data that is collected. This can help visualize how different variables in the system relate to each other. 

![[Pasted image 20260406021226.png]]
There are five stages of an empirical model
	1. What do you want to change? - Have a variable component in the system to test how it affects the system when changed.
	2. What will stay constant? - Having too many variables will give inconclusive results so it is essential that most of the components of a system remain the same.
	3. Complete a controlled test - Tests should be conducted in a stabilized environment
	4. Measure output reaction - Record data from the testing
	5. Create Empirical equation - Using the data acquired a more accurate mathematical model can be derived
Data collection is vital and having many accurate data points assists in the usefulness of testing. Data points should be relevant and doable and do not always have to follow a pattern, but it helps if it does. Recording this data on a table in by convention to keep it organized. A common practice is to graph the data points and generate a trend line for the data.

Predictive and Proactive engineering is the practice of using data and modeling to increase the reliability of a prototype and decrease the amount of prototypes needed to be made.

Do not overcomplicate a model it is best to leave out any unnecessary variables and keep the model simple.
