## Notes

A function is a rule that assigns each element $x$ of one set to exactly one element $f(x)$ of another set where $x$ is the domain and $f(x)$ is the range. Functions can be represented verbally algebraically graphically and numerically and take the form typically as $y = f(x) = x^{2} + 1$ where x is independent and y is dependent. Functions can only have one output for each unique input.

Values can be solved for $x$ by simplifying a function to its base parts and setting the variable $x$ to a value.

Piecewise functions are functions that are used to get the output when the input meets certain conditions.

Composite functions are when a function is used as the input of another function $f(g(x))$ 

Inverse functions are functions where the domain and range is another function's range and domain and the function is one to one which means that $f(a) \ne f(b)$ when $a \ne b$ or that each input maps to a unique output. $f^{-1}(b) = a$ if and only if $f(a) = b$.

Exponential function laws if $f(x) = b^x$ and $b \gt 0$ and $b \ne 1$ then for $x = n$ and n is positive then $b^n = b_1 \times b_2 \times ... b_n$ and $b^{-n} = \frac{1}{b^n}$. For ratio exponentials $b^{\frac{p}{q}} = \sqrt[q]{b^p}$.
For exponential functions with irrational exponents i.e. $\sqrt{2}$ can be solved by taking the limit $b^x = \lim\limits_{r \to x} b^r$ where $x$ is an irrational number and $r$ is a rational number.
$b^x$ is a continuous function with the domain $(-\infty,\infty)$ and range $(0,\infty)$. Algebraic equalities of exponentials include $a^{x+y} = a^xa^y$ , $a^{x-y} = \frac{a^x}{a^y}$ , $(a^x)^y = a^{xy}$ and $(ab)^x = a^xb^x$
If $f(x) = a^x$ is multiplicative over any interval of length $k$ to the factor of $a^k$ then $f(x + k) = a^ka^x = a^kf(x)$ 

Logarithms are the inverse of exponential where the log base a of x is a to the power of what will equate to x and written $log_a(x) = y$  -> $a^y = x$. The logarithm laws are $log_a(xy) = log_a(x) + log_a(y)$ , $log_a(\frac{x}{y}) = log_a(x) - log_a(y)$ , $log_a(x^y) = ylog_a(x)$ , $log_a(x) = \frac{log_b(x)}{log_b(a)}$.
