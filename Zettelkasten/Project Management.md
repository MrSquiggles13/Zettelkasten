# Project Management

## Notes

A project is a series of non routine tasks that resolve to an end goal of making a desirable outcome or deliverable. Project management is maintaining those tasks in several areas. A project has either one out of two outcomes completed or discontinued and most end up in the latter. Project management utilizes knowledge, skill and varied techniques to fulfill a projects requirements. It is important to evaluate a project's constraints and develop a way to handle them appropriately.

Some constraints are:
- Resources - The materials, supplies, and people that'll be used
- Cost - Most of the time is financial budget but also involves limited resources and time
- Risk - The hazards that can occur and how to mitigate them
- Time - How long things will take
- Quality - The threshold for the project to meet requirements in a desirable manner

Project Management Cycle

The project management cycle involves:
- Initiating a project by forming the team(s) and figuring out what the project is
- Planning the tasks to be done who will do them and in how long
- Executing the steps to finish tasks at hand
- Monitor and control the team and tasks being done
- Complete the project

An effective project plan should state what tasks need to be done, by whom, for how long, and how much it should cost. Tasks should be as specific as possible and if need be broken down into smaller tasks. Tasks should also be listed in order with time constraints and the relationship tasks have if there are any. Tasks can have three relationships: Concurrent - which means tasks are independent and can be done at the same time; Dependent - task A cannot start until task B is done; Lag - a task is delayed by some external circumstance. Also building effective communication is essential for a project to have cohesion between all those involved. 

A Gantt chart can be used to break down tasks and schedule the expected length of time needed for said task.

A good time management skill for project planning is to frame out three different time scenarios: Worst case, Best case and Expected case. When running behind schedule the root cause should be identified and a critical path made to resolve it.

When conflicts arise during a project they must be resolved immediately. Effective communication and conflict resolution are essential to keep a team moving forward.
