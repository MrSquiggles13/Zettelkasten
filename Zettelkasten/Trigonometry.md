# Trigonometry

## Notes

An inverse trigonometric function takes in a displacement and outputs an angle in radians. The trigonometric function that is taken the inverse of must have a constrained domain in order to make it one to one as per the inverse function rules.
$asin(\theta) = [\frac{-\pi}{2},\frac{\pi}{2}]$ $acos(\theta) = [0,\pi]$ $atan(\theta) = (\frac{-\pi}{2},\frac{\pi}{2})$
